      See your software as a landscape

      Paste a public GitHub repository or a local path above. The code is analyzed with fast static analysis, then a local model (Ollama or LM Studio) writes short descriptions. Nothing leaves your machine.

      • Double-click a box to zoom into it

        Shortcuts

        double-click Enter
        zoom into the selected box (⊕)
        Backspace
        zoom out a level
        Esc
        clear the selection
        /
        find anything in the whole model
        F
        fit the diagram to the screen
        L
        show or hide relationship labels
        D
        switch layout direction
        1 … 6
        highlight a kind of box: system, container, component, file, person, external (again to clear)
        ?
        this help

        Hover a box to highlight what it talks to. Every view has its own URL, so the back button works and you can share the exact level you are discussing.
